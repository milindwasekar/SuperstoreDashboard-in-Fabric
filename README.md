# SuperstoreDashboard-in-Fabric
### Project Objective: End-to-End Superstore Sales Dashboard Using Microsoft Fabric

The Superstore dataset is stored in a SQL database named **Superstore**. The objective is to connect Microsoft Fabric to the SQL database, explore and analyze the available data, and develop an end-to-end sales analytics solution.

The project will involve data discovery, data ingestion, data transformation, and data modeling based on business requirements and appropriate assumptions. Using the prepared data model, an interactive sales dashboard will be developed to analyze sales performance, profitability, product and category trends, regional performance, and customer purchasing patterns.

The solution will demonstrate the end-to-end capabilities of Microsoft Fabric, from connecting to the source SQL database to delivering actionable business insights through interactive reports and visualizations.
### Key deliverables
- Data connectivity: Connect Microsoft Fabric to the Superstore SQL database.
- Data exploration: Identify relevant tables, columns, relationships, and data quality issues.
- Data transformation: Clean and prepare the data for reporting.
- Data modeling: Design an appropriate data model based on business requirements and assumptions.
- Dashboard development: Build interactive reports covering sales, profit, products, categories, regions, and customers.
- Business insights: Identify Oders,Sales,Profit KPT its trend wrt Previous year , profitability drivers,other important metrics  and areas for improvement.
